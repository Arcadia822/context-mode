# Decisions after review r4 (2026-10-15)

One row per root cause, merged from 4 researchers (out/fix-r4/res-*.json: docs-A 65, docs-B 76, issues-1 33, issues-2 26). Conflicts were settled with the decision rule: (1) keep owner rules, (2) do not re-break a v1 fix, (3) simplest single path.

## Conflicts settled

- **A4**: One write path into the one shared context.db per project: the server writes journal rows from its own ctx_* handlers; hooks write rows only for host tools. Both use the single #645 path resolver. Merges I2-13 (D8 "server never writes" is retired).
- **I2-13**: MERGED into A4: hooks and server both resolve the DB path through the #645 resolver; no per-caller DB.
- **A25**: Add a row with the exact condition. On a miss: hard error naming the doctor fix. No fallback (owner rule).
- **A23**: Name QWEN_PROJECT_DIR as the single source; delete the cwd fallback (owner rule: no fallback chains); GP7 case asserts doctor reports the missing source.
- **A12**: Resolve the node binary at hook-run time with one lookup (no install-time literal, no second path). Covers #1090 and #841. Merges I1-8.
- **I1-8**: MERGED into A12.
- **A46**: #1251 closes via node:sqlite (r3 Q10): no native module ships. Add a Windows cold-start, no-network GP test that mirrors #861.
- **I1-25**: closed-by-design: node:sqlite (r3 Q10) removes better-sqlite3 and ensure-deps self-heal. Merges A46.
- **I1-6**: covered-by-test (overrides wont-fix): r3 Q19 says proxy env YES with an SSRF check. #1184 gets a GP case; SSRF runs on the resolved proxy target in the fetch process (A8, A52).
- **A52**: MERGED into A8: honour HTTP_PROXY only with the resolved-target SSRF check in the same process.
- **I1-31**: covered-by-test (overrides wont-fix): hard deny stays with v1 scope (owner rule), so D10 does not make #945 moot. Keep v1 WebFetch deny behaviour; add a GP3 case for claude.ai artifact URLs.
- **I2-22**: covered-by-test (overrides wont-fix): session TTL keyed off last activity is a v1 crash/data-loss fix; rule 2 forbids re-breaking it. Add GP6 case.
- **A53**: Merge with I2-3: no idle-shutdown timer (re-broke hosts in #568); lifecycle is stdin-EOF/ppid plus the A48 SIGTERM->SIGKILL escalation; GP9 lists #999 and tests OpenCode/KiloCode.
- **A51**: Decide now (owner delegated): name the mechanism in the ADR this row cites; no needs-decision rows remain.
- **A30**: git-checkout via ctx_upgrade for OpenCode (no npm for v2, owner rule).
- **I1-29**: wont-fix: no target agent enforces a tool-count allow-list; 9 tools fixed (A1).
